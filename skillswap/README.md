# SkillSwap

## Project Overview
SkillSwap is a skill-sharing platform that allows users
to offer their skills and request learning sessions
with other members.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Swagger / OpenAPI

## Database
Database Name: skillswap

Tables:
- members
- skill_offers
- session_requests

## Backend Features
- Member Management
- Skill Offer Management
- Session Request Management
- REST API
- MySQL Database Integration
- Swagger API Documentation

## Running the Application

Run the following command:

```bash
.\mvnw.cmd spring-boot:run
